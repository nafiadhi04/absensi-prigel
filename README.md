📝 Deskripsi Proyek

Repositori ini merupakan sistem manajemen absensi berbasis web yang dikembangkan selama mengikuti program Prigel bersama IT Pedia. Fokus utama dari proyek ini adalah melakukan pengembangan serta penambahan fitur fungsional pada platform website untuk meningkatkan efisiensi pencatatan kehadiran. Absensi menggunakan kamera yang dilengkapi dengan model face recognition dan face detection. Data wajah terbaru akan selalu disimpan di database sehingga hasil deteksi lebih konsisten.

🚀 Fitur Utama

Sistem Presensi: Pencatatan kehadiran digital yang terstruktur.

Panel Admin : Fitur tambah, edit, dan log data absensi

Manajemen Data: Pengolahan data absensi yang efisien di sisi server.

Antarmuka Responsif: Desain UI/UX yang optimal menggunakan standar web.

🛠️ Teknologi yang Digunakan

Programming Languages: Python, JavaScript

Frontend: HTML, CSS

Database: MySQL
